# Docs

本目錄用於保存 AJO Living 產品、原型、整合、資料與交付文件。

## 目錄索引

- `AGENTS.md`: docs 目錄的 agent 記憶邊界與維護協議。
- `PROMPT_INDEX.md`: AI prompt、agent 規則、工具描述與維護協議索引。
- `architecture/`: 系統架構與模組邊界文件。
- `development/`: Vue、React、Go 與 API 文件生成等開發規範。
- `deployment/`: 部署、運維與環境交付文件。
- `product/`: 產品需求、驗收、稽核與頁面規格。
- `product/legacy-requirements/`: 早期樓盤、服務住宅與二手交易需求草案。
- `product/serviced-residence/`: 服務住宅頁面與管理端規格。
- `product/unified-channel/`: 統一頻道系統的 API、資料模型、頁面流轉與交付計畫。
- `integrations/`: 外部 App、舊系統與 AJO 模組映射文件。
- `data/`: 地址表、參考資料與配置資料。
- `prototypes/`: HTML 原型與拆分後的可預覽原型資產。
- `backups/`: 歷史備份檔案。
- `prompts/`: 頁面、表單與 UI 風格提示詞。

## 歸檔規則

新增文件優先按用途放入以上目錄；根目錄只保留索引與少量全局說明文件。
