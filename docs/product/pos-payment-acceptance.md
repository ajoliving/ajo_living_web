# POS 物業繳費驗收清單

## 前置條件

- AJO Web 與 AJO 後端使用同一版本程式碼。
- 已準備一個已綁定 ismart 的普通會員帳戶。
- 已準備一個 ismart Staff 帳戶。
- 測試單位需有待繳 POS 賬單。
- 測試大廈需有現金、支票、銀行轉賬及線上支付設定。

## 自動檢查

- 前端執行 `npm run build`，結果需通過。
- 後端執行 `go test ./...`，結果需通過。

## 版本連通性檢查

- 未登入狀態請求 `/api/v1/me/payments/pos/overview` 應返回 401。
- 未登入狀態請求 `/api/v1/me/payments/pos/fees` 應返回 401，不應返回 404。
- 未登入狀態請求 `/api/v1/me/payments/pos/bank-accounts` 應返回 401，不應返回 404。
- 未登入狀態請求 `/api/v1/me/payments/pos/orders/query` 應返回 401，不應返回 404。
- 若新增 POS API 返回 404，代表目前運行中的後端不是包含本輪 POS 遷入的版本。

## 普通會員流程

- 進入 `支付中心 / 單元`，可選擇大廈、樓層與單位，儲存後返回支付中心。
- 進入 `賬單`，待繳賬單可加入購物車、取消加入、全選加入。
- 使用 `單筆結賬` 建立 H5 訂單，頁面可進入 `訂單`。
- 進入 `購物車`，只顯示目前單位已加入的賬單。
- `購物車` 可刪除單筆賬單、清空目前單位購物車。
- `購物車` 可使用微信、支付寶、雲閃付 H5 或 QR 建立線上訂單。
- `購物車` 可使用現金、支票、銀行轉賬提交線下繳費。
- 銀行轉賬與支票在未選銀行戶口時不可提交。
- 線下繳費成功後，購物車目前單位賬單被清空，並可在 `歷史` 查到記錄。
- 普通會員導航不顯示 `會計`。
- 普通會員直接進入 `會計` 路徑時，不可看到會計資料。

## 訂單流程

- `訂單` 可識別 H5 返回的 `mch_order_no` 或 `pay_order_id`。
- `訂單` 可刷新狀態。
- 未完成 H5 訂單可繼續支付。
- QR 訂單可展示二維碼。
- 可查看訂單詳情彈窗。
- 可關閉或取消目前單位可見的訂單。

## Staff 流程

- ismart Staff 進入支付中心後，導航顯示 `會計`。
- `會計` 顯示現金待清機與支票待清機分組。
- 現金與支票待清機項目預設全選。
- 可取消選取、重新全選並提交清機。
- 清機成功後可刷新列表。
- 可查看清機歷史與清機詳情彈窗。
- Staff 在 `歷史` 可按日期範圍、日期類型、收款方式查詢。
- Staff 在 `歷史` 可按可見單位列表批量查詢。

## 權限與資料邊界

- 前端不得直接請求舊 POS 服務網址。
- 所有 POS 讀寫均需經由 AJO 後端 `/api/v1/me/payments/pos/*`。
- 普通會員只能查目前選中且可見的單位。
- Staff 只能查可見大廈與可見單位。
- 線下報數 payload 的大廈與單位需以 AJO 後端校驗後的上下文為準。
- H5 訂單缺少單位上下文時，不應通過 AJO 可見性校驗。
