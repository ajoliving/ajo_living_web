# 服務住宅頁面總覽

## 目標

服務住宅模組用於展示可月租或日租的酒店式住宅、服務式公寓與長短租住宿項目。整體體驗需要偏正式、清晰、可信，讓租客可以快速篩選、比較房型、查看設施服務，並透過 WhatsApp、電話或網站進一步查詢。

## 使用者角色

- 租客：搜尋服務住宅、比較價格與房型、查看設施、發起查詢。
- 發布者：建立服務住宅項目、維護多個房型、更新圖片與服務資料。
- 會員：管理自己發布的服務住宅、編輯草稿、重新發布。
- 管理員：審核、編輯、下架或維護平台內所有服務住宅。

## 核心頁面

1. 服務住宅篩選列表頁
2. 服務住宅公開詳情頁
3. 服務住宅發布 / 編輯頁
4. 服務住宅預覽頁
5. 會員中心服務住宅列表頁
6. 會員中心服務住宅編輯頁
7. 管理端服務住宅列表頁
8. 管理端服務住宅編輯頁

## 整體視覺方向

- 公開頁可使用暖銅色主題，呈現酒店式住宅的高級感與信任感。
- 表單、會員中心與管理端需要更偏工作台風格，保持密集、清楚、正式。
- 卡片圓角控制在 8px 左右，避免過度圓潤。
- 頁面以資訊效率為優先，不做行銷式空洞 Hero。
- 圖片必須真實承載內容，避免只用抽象背景或裝飾圖。

## 主要資料

- 住宅名稱、住宅名稱 Eng
- 地址、地址 Eng、地區
- 圖片集
- 網站、WhatsApp、電話、傳真
- 房間種類：房型名稱、面積、月租、日租、最短逗留
- 住宅資料標籤
- 設施標籤
- 服務標籤
- 附加收費項目
- 廣告等級與 AJO Point 扣點

## 流程

租客流程：
服務住宅入口 -> 篩選列表 -> 詳情頁 -> 查看房型 -> 解鎖聯絡方式 / WhatsApp 查詢。

發布者流程：
會員中心 -> 新增服務住宅 -> 填寫資料 -> 上傳圖片 -> 預覽 -> 發布 -> 會員中心管理。

管理員流程：
管理端 -> 服務住宅列表 -> 搜尋 / 篩選 -> 查看與編輯 -> 保存或下架。
