# 服務住宅篩選列表頁

## 頁面目標

讓租客快速找到合適的服務住宅，並能按地區、價格模式、價格範圍、面積、設施與關鍵字縮小結果。列表卡片需要一眼看到住宅名稱、最低價格、地點、面積與主要設施。

## 頁面結構

1. 頁面標題區
   - 標題：服務式住宅
   - 簡短說明：月租、短租及彈性入住選擇。

2. 篩選區
   - 地區：不限、香港島、九龍、新界及細分地區。
   - 價錢模式：月租 / 日租切換。
   - 價錢區間：不限、自定、5000 以下、5000-10000、10000-20000、20000-50000、50000 以上。
   - 面積區間：不限、自定、100 以下、100-500、500-1000、1000-2000、2000 以上。
   - 設施：不限、獨立廚房、寬頻上網、泊車、餐廳、接駁巴士、泳池。
   - 關鍵字：搜尋住宅名稱、地址、地區或服務資料。
   - 清除篩選、搜尋按鈕。

3. 排序區
   - 預設排序：廣告權重優先，其次最新更新。
   - 價格由低至高。
   - 價格由高至低。
   - 面積由大至小。

4. 列表卡片區
   - 封面圖片。
   - 住宅名稱 / 英文名稱。
   - 地址或地區。
   - 最低月租或最低日租。
   - 最小房型面積。
   - 最短逗留。
   - 主要設施標籤。
   - 廣告角標：黃金、置頂、即走等。
   - 詳情入口。

5. 空狀態
   - 顯示「暫時沒有符合條件的服務住宅」。
   - 提供清除篩選按鈕。

## 互動需求

- 切換月租 / 日租後，價格範圍與卡片價格同步更新。
- 自定價格或面積輸入後可立即查詢。
- 設施可多選。
- 關鍵字搜尋需要支持住宅名稱與地址。
- 點擊卡片進入公開詳情頁。

## 手機顯示

- 手機只作瀏覽網頁，不是 native app。
- 篩選區可收合為篩選按鈕。
- 列表卡片一欄顯示。
- 價格、名稱、地區需要保持第一屏可讀。

## Stitch 生成重點

請生成一個正式、清晰、暖銅色調的服務住宅列表頁。頁面需要像成熟地產平台，不要像行銷 landing page。篩選區要密集但不擁擠，列表卡片要方便快速比較。
