# 管理端服務住宅編輯頁

## 頁面目標

讓管理員編輯任一服務住宅，並能查看發布者、狀態、廣告等級、房型、設施、聯絡與圖片資料。此頁需要與會員中心服務住宅編輯保持一致，但增加管理欄位與審核操作。

## 頁面結構

1. 頂部管理欄
   - 返回列表。
   - 住宅狀態。
   - 保存。
   - 預覽。
   - 上架 / 下架。

2. 發布者資訊
   - 發布者姓名。
   - 電話。
   - Email。
   - 身份：業主或地產代理。

3. 住宅內容表單
   - 與發布 / 編輯頁一致：
     - 住宅名稱。
     - 住宅名稱 Eng。
     - 地址。
     - 地址 Eng。
     - 地區。
     - 網站。
     - WhatsApp。
     - 傳真。
     - 房間種類。
     - 住宅資料。
     - 設施。
     - 服務。
     - 附加收費項目。
     - 圖片。

4. 廣告資料
   - 廣告等級。
   - AJO Point。
   - 權重。
   - 到期時間。

5. 內部備註
   - 管理員備註。
   - 不公開顯示。

## 互動需求

- 保存後不能丟失任何房型或標籤資料。
- 圖片排序與封面設定可調整。
- 上架 / 下架需要確認。
- 預覽打開公開詳情頁效果。

## 視覺需求

- 管理端風格，清晰、緊湊、正式。
- 重要風險欄位需要醒目，但不要使用過度警示色。
- 表單分段明確，避免長表單失去方向。

## Stitch 生成重點

請生成一個服務住宅管理端編輯頁。它需要像成熟後台系統，不是公開展示頁。頁面以可維護、可審核、可快速保存為核心。
