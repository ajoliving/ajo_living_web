# 服務住宅發布 / 編輯頁

## 頁面目標

讓發布者以四步流程建立或編輯服務住宅。表單需要支持住宅資料、多房型、設施服務、附加收費、聯絡資料與圖片上傳。會員中心與管理端應復用同一套編輯體驗。

## 流程步驟

1. 住宅類別
2. 住宅內容
3. 預覽
4. 完成

## 第一步：住宅類別

需要保留：
- 業主或地產代理。
- 本地 / 海外。
- 廣告等級。

不需要：
- 租售類型，服務住宅固定為放租。
- 一般放盤 / 多於一伙或發展商項目。
- HKD 付款顯示。服務住宅廣告只顯示 AJO Point。

## 第二步：住宅內容

1. 項目資料
   - 住宅名稱。
   - 住宅名稱 Eng。
   - 地址。
   - 地址 Eng。
   - 地區。
   - 地圖位置。
   - 網站。
   - WhatsApp：只填手機號碼，系統轉換為 WhatsApp 連結。
   - 傳真。
   - 最短逗留預設值。

2. 房間種類
   - 可新增 / 刪除多個房型。
   - 欄位：
     - 房型名稱。
     - 房型分類。
     - 面積。
     - 最短逗留數值。
     - 最短逗留單位：日 / 月。
     - 月租最低 / 最高。
     - 日租最低 / 最高。
   - 若最短逗留單位為月，只顯示月租欄位。
   - 若最短逗留單位為日，只顯示日租欄位。
   - 房型可以只填月租或只填日租，但至少要有一個有效價格，除非選擇價格僅供參考。

3. 設施與服務
   - 設施標籤輸入框。
   - 服務標籤輸入框。
   - 附加收費項目標籤輸入框。
   - 標籤可手動輸入，確認後新增。
   - 標籤右側有紅色 X 可刪除。
   - 支持快捷標籤。

4. 住宅資料
   - 不需要傳統標題欄位。
   - 使用住宅資料標籤輸入框。
   - 快捷標籤例子：
     - 每月租金已包水電差餉及管理費
     - 每週一次房間清潔服務（星期日及公眾假期除外）
     - 有上網連接的智能電視
     - 有免費無線上網提供
     - 夾萬
     - 設備齊全的廚房設施
     - 部份單位設有私人露台
     - 每天日報
     - 早餐

5. 聯絡資料
   - 預設帶入個人資料中的用戶名、電話、Email。
   - 發布者可以修改。
   - WhatsApp 只需要填手機號碼。

6. 圖片上傳
   - 沿用樓盤上傳邏輯。
   - 至少一張圖片才能發布。
   - 第一張作封面。

## 必填與校驗

- 必填欄位需要紅色 *。
- 住宅名稱必填。
- 地區必填。
- 至少一個房型必填。
- 房型名稱必填。
- 房型價格或價格僅供參考二選一。
- 至少一張圖片才能發布。

## 預覽

預覽頁需要接近公開詳情頁，不要只做簡單摘要。應能看到：
- 圖集。
- 房型表。
- 住宅資料。
- 設施與服務。
- 右側摘要卡。

## Stitch 生成重點

請生成一個正式、緊湊、工作台式的服務住宅發布 / 編輯頁。它是 Web 表單，不是 app。四步流程需要清晰，表單卡片需要緊湊，適合大量欄位輸入。
