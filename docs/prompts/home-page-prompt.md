# Home Page UI Prompt

## 可直接使用的 Prompt

完善 AJO Living 首頁的版面與既有功能入口。AJO 是物業管理主系統，首頁優先讓住戶進入「我的大廈」與已接通的生活服務。修改前先讀現有 `web_new` 頁面、路由與 API，不引入尚未接通的功能。

## 頁面結構

1. 緊湊實景封面
   - 品牌標題為 `AJO LIVING`，使用本地香港住宅實景照片。
   - 繁中副標題為「智慧大廈 · 智能生活 · 租務一站式」。
   - 主要操作為「我的大廈」，連往 `/building`，由既有路由守衛處理登入。
   - 桌面及手機首屏均須能看到下方入口，不使用全螢幕輪播或捲動舞台。

2. 六個常用服務
   - 固定順序：我的大廈 `/building`、樓盤租售 `/properties`、智能門禁 `/building?tab=access`、超市格價 `/supermarket-offers`、租金走勢 `/trend`、會話 `/notifications?tab=conversations`。
   - 使用正式連結與既有圖示；桌面六欄、手機兩行三欄。
   - 首頁不設頂部工具列，不提供額外搜尋、屋苑選擇或通知入口；封面直接接續全站導航。會員環境資料沿用已保存大廈。首頁手機底欄使用首頁、樓盤、門禁、我的大廈、會話；其他頁面保留既有導航。

3. 超市優惠
   - 讀取既有 `/api/v1/supermarket-offers/summary`，展示 `bestDiscounts` 前四項，保持接口原有順序。
   - 商品卡直接共用超市優惠列表的 `SupermarketProductCard.vue`，統一商品圖、品牌標籤、名稱與規格、並列最低價門店、實付單價、實際原價及每件節省。價格沿用超市頁的門店排序與既有後備規則，不另外推算。
   - 收藏沿用既有接口及登入引導，失敗不改本地收藏狀態；原價只取最低價門店實際資料，不拿其他門店現價充當原價。
   - 商品卡連往該商品正式詳情，「更多優惠」連往既有超市頁。
   - `metadata.upstreamAvailable=false` 屬可重試錯誤，不當作正常空結果。

4. 社區環境
   - 透過同源 `GET /api/v1/home/environment` 讀取公開天氣；會員沿用「我的大廈」目前已保存大廈，不另建選擇器或要求定位。
   - 後端確認大廈可見範圍後，優先採用明確地圖標點，其次以正式名稱及門牌核對官方座標。不得以地圖視角中心、模糊搜尋命中或樓盤發佈座標替代。
   - 標明氣溫觀測站、分區過去一小時最高雨量、一般 AQHI 實測站及觀測時間；明日預報維持全港範圍。
   - 海景灣採赤柱、尚珀·天際採京士柏、柏蔚山採將軍澳作公開參考，標明「參考區域」。這些映射不作實際屋苑座標。未能核實會員位置時，天氣回退為香港天氣。

5. 交通與生活提示
   - 交通展示各方向下一班港鐵；參考站分別為海洋公園、宋皇臺及將軍澳。使用絕對到站時間計算倒數，過期班次不顯示。
   - 生活提示展示今日或下一個公眾假期、可信私家車空位，以及醫管局第 IV、V 類合併輪候中位數。不得把合併讀數標成單獨次緊急或據此推薦就醫地點。
   - 港鐵、私家車位、急症室輪候及公眾假期查詢使用 `https://apis.hk.skylinedances.com/?page=transport`、`?page=parking`、`?page=health` 和 `?page=holidays`。無讀數時亦保留入口，不傳會員、屋苑或地址資料。發布時先驗證儀表板能直接開啟對應欄目，再部署 AJO 的入口。
   - 所有動態資料經 AJO 後端代讀，Redis 共用來源、同鍵合併取數、設時限和上游併發上限，會員可見範圍不可快取。

6. 物業資訊與最新樓盤
   - 三則物業資訊使用可辨讀的 16:9 本地封面及可核對的原始來源。
   - 讀取既有公開樓盤列表，查詢 `page=1`、`page_size=3`、`sort_by=latest`。
   - 顯示真實封面、地區、物業類型、標題、售價或月租及面積；沿用現有資料格式與詳情路徑。
   - 不混入聯絡人私有資料，不用靜態示例替代接口結果。
   - 樓市資訊及社區會話沿用既有路由，未接通的智能家居商品與硬件目錄不設空入口。

7. 我的大廈
   - 沿用正式物業選擇與授權。顯示目前大廈的天氣、全港九天預報及可用生活資訊。
   - 手機以三欄展示九個既有服務；待跟進只展示目前物業真實未完成個案，沒有資料不顯示。

## 狀態與響應式

- 超市、社區環境與樓盤各自載入；一區失敗不得阻塞其他區塊或快捷入口。
- 每區提供骨架、空態及錯誤重試；只重讀失敗區塊。
- 商品圖片失效沿用超市卡片首字後備，樓盤使用圖示後備，保持尺寸及連結可用。
- 超市商品桌面四欄、手機兩欄，載入骨架亦為四張，卡片尺寸與超市頁一致；樓盤桌面三欄、手機單欄。
- 320px、390px、430px、平板及桌面不得有頁面橫向溢出，底部入口不得被固定導航遮擋。
- 繁體中文及 English 使用完整對齊的 i18n key；主題沿用全站語意 token，不套用參考 PDF P.3 色票。
- 實作放在 `web_new/src/pages/home/`，以 `HomePage.vue` 統一協調資料及狀態，局部樣式放 `styles.scss`。

## 範圍限制與驗證

- 不加入虛構社區動態、未接入的租務管理、智能家居商品或其他佔位入口。
- 不向首頁返回大廈座標、住戶地址或文件。
- 文案正式、簡潔，不顯示資料來源宣傳、開發說明或尚未提供的能力。
- `HomePage.spec.ts` 覆蓋真實路由、優惠排序與價格、兩區獨立狀態、重試、圖片後備與語系切換。
- 執行首頁測試、語系測試及正式建置，並以瀏覽器檢查手機與桌面。使用 mock 時明確區分版面驗證與真實接口驗證。
- 不替使用者啟動前端或後端服務。
