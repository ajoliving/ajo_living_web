# Home Page UI Prompt

## 可直接使用的 Prompt

請建立 AJO Living 的首頁，面向香港社區生活、二手交易、樓盤放售與服務住宅入口。首頁不是一般 marketing landing page，而是一個沉浸式入口頁：首個視窗是大標題、城市剪影與 3D 圖片輪播；往下是全螢幕 sticky 圖片舞台，隨滾動切換三個主模組；最後是三張正式的模組入口卡。所有 UI 文案使用繁體中文，品牌名稱 AJO Living 保持英文。不要使用表情符號，不要加入開發說明或教學文字。

## 整體頁面

1. 頁面基調
   - 高級、正式、沉浸式。
   - 背景使用柔和多色漸層，但不要單一紫色或單一深藍。
   - 可以使用暖銅、低飽和綠、淡灰、墨綠與柔和中性色混合。
   - 頂部導航在首頁可透明覆蓋。

2. 頁面結構
   - 第一段：首個視窗 spacer，包含大標題、subtitle、城市 skyline、3D 輪播。
   - 第二段：sticky stage，使用全螢幕圖片與文字切換展示三個模組。
   - 第三段：模組說明卡列表，一個模組一張卡。

## 第一段首個視窗 Spacer

1. 尺寸
   - 高度約 `100svh + 5.1rem`。
   - 內部 grid 分兩列：上方文案區，下方輪播區。
   - padding top 使用 `clamp(5.8rem, 10vh, 7.5rem)`，避免被透明導航遮住。

2. 背景
   - 整個 stage-showcase 使用多層背景：
     - 左上柔和 radial glow。
     - 右上柔和 radial glow。
     - 一個由左下到右上的多色線性漸層。
   - 背景不要太暗，文字需要清晰。
   - 可加入一個大型柔光圈在首個視窗中上部，透明且模糊。

3. 文字
   - 文字置中。
   - H1：「香港屋苑租住與社區生活平台」。
   - H1 使用 display font，字級 `clamp(3rem, 6vw, 5.8rem)`。
   - 行高約 `0.92`。
   - subtitle：「從首頁直接進入二手、樓盤放售與服務住宅。」或相近正式文案。
   - subtitle 字級 `clamp(1rem, 1.4vw, 1.18rem)`，行高 1.85。
   - 文案整體向上微移約 20%，讓輪播和 skyline 有空間。

4. 城市 skyline
   - 在首個視窗底部偏上，絕對定位。
   - 寬度 100vw。
   - 可使用香港天際線、建築剪影或透明 PNG。
   - 混合模式可使用 screen。
   - opacity 約 0.76。
   - 最大高度桌面 `24rem` 至 `38rem`，手機 `16rem` 至 `24rem`。

## 首個視窗 3D 圖片輪播

1. 位置與尺寸
   - 放在首個視窗底部區域。
   - 高度 `clamp(17rem, 38svh, 25.5rem)`。
   - 寬度 100%。
   - 使用 perspective 1800px。
   - 支援 auto rotate、wheel 與 drag。

2. 卡片
   - 每張輪播圖比例 16:10。
   - 桌面寬度 `min(26vw, 360px)`。
   - 手機寬度 `min(25rem, 72vw)`。
   - 圓角 16px。
   - 白色透明邊框。
   - 陰影 `0 18px 36px rgba(22,24,34,0.18)`。
   - 圖片鋪滿，object-cover。

3. 動態
   - 卡片圍繞中心水平移動。
   - 中央附近的卡片清晰且較大，遠離中心的卡片可有輕微 blur。
   - 根據水平位置做 rotateY、translateZ、scale。
   - hover 或拖拽時可以暫停自動播放。

## Sticky Stage

1. 整體
   - stage 高度約 `440vh`，手機約 `380vh`。
   - 內部 `.layers` 使用 sticky，top 0，高度 100vh。
   - 背景為柔和漸層。
   - 有向上的陰影，使它與首個視窗銜接自然。

2. 圖片層
   - 三個模組各有一張全螢幕背景圖：
     - 二手交易。
     - 樓盤放售。
     - 服務住宅。
   - 圖片使用 SVG mask 或等效方式做網格開啟動畫。
   - 圖片鋪滿全螢幕，object-cover，亮度略降到 0.82。

3. 遮罩
   - 疊加黑色垂直漸層：
     - 上方透明度約 14%。
     - 中段約 8%。
     - 底部約 52%。
   - 確保文字在白色圖片上仍清晰。

4. 文字層
   - 文字在畫面底部，使用絕對定位。
   - padding 使用 `clamp(1.5rem, 4vw, 3rem)`。
   - 文字 uppercase。
   - H1 是模組名稱，例如「二手交易」「樓盤放售」「服務住宅」。
   - H1 字級 `clamp(4rem, 7vw, 10rem)`，行高 0.86，最大寬度約 11ch。
   - H2 是狀態，例如「開放中」「即將上線」，字級 0.95rem 至 1.2rem，letter spacing 0.24em。
   - 描述文字最大寬度 34rem，行高 1.9，不 uppercase。
   - 文字切換可用 clip-path 從下往上展開，再退出。

5. 進度條
   - 置於底部中央。
   - 寬度 `min(30rem, 72vw)`。
   - 三段，每段高度 0.2rem。
   - 底色白色 18% 透明，填充白色 96%。
   - 隨 scroll progress 填充。

## 模組入口卡

1. 位置
   - 在 sticky stage 後方。
   - 使用 section shell 置中。
   - 卡片垂直堆疊，間距 24px。
   - 底部留 32px。

2. 卡片外觀
   - 背景為 panel surface。
   - padding 手機 24px，桌面 32px。
   - 輕邊框、柔和陰影。
   - 內部有一個非常淡的模糊光圈作為背景，但不要太裝飾。
   - active 卡片上移 4px，陰影加深。

3. 卡片內容
   - 頂部左側：
     - kicker：「01 / 二手交易」等。
     - 狀態 pill：「開放中」或「即將上線」。
   - 主標題：
     - display font，`clamp(2rem, 4vw, 2.9rem)`。
   - 描述：
     - 16px，行高 32px，muted。
   - 右側：
     - 模組序號，例如「01」，超大但低透明度。
     - icon 方塊，尺寸約 `3.5rem`，圓角 `1.35rem`。
   - 下方：
     - 三個 metric 小卡，三欄。
     - 每個 metric 有大數字或狀態值，以及小標籤。
     - 右側放操作按鈕：
       - 二手交易有「瀏覽列表」「篩選帖子」。
       - 其他模組顯示狀態 pill 或即將上線。

## 文案資料

可使用以下模組內容：

1. 二手交易
   - 狀態：開放中。
   - 描述：瀏覽屋苑二手帖子，支援篩選、聊天與成交跟進。
   - 指標：精選、來源 API、狀態開放中。

2. 樓盤放售
   - 狀態：即將上線。
   - 描述：樓盤放售入口，後續支援詳情、預約看房與線索管理。
   - 指標：狀態即將上線、對象業主 / 代理、流程看房 / 諮詢。

3. 服務住宅
   - 狀態：即將上線。
   - 描述：短租與月租服務住宅入口，後續補充入住與配套流程。
   - 指標：租期短租 / 月租、服務入住支援、狀態即將上線。

## 響應式要求

- 手機版 H1 字級縮小到 `clamp(2.6rem, 11vw, 4rem)`。
- 手機版首個視窗文案向上微移 14%。
- 手機版輪播高度約 `clamp(15.5rem, 35svh, 20.5rem)`。
- 手機版 sticky stage 高度約 `380vh`。
- 進度條寬度改為 `min(22rem, calc(100vw - 2rem))`。
- 模組卡片右側序號與 icon 可以下移或縮小，避免與標題重疊。

## 視覺限制

- 不使用表情符號。
- 不要使用卡片包住首個視窗主標。
- 不要把首頁做成左右圖文 hero。
- 不要放過多介紹段落。
- 首個視窗必須以品牌和平台感為第一視覺訊號。
- 圖片要真實、明確，避免模糊抽象背景。
