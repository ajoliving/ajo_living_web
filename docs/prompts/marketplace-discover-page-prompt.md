# Marketplace Discover Page UI Prompt

## 可直接使用的 Prompt

請建立一個「二手鄰里交易 Discover」頁面，用於展示推薦好物與不同主分類的商品流。頁面要簡約、正式、圖片驅動，不要出現「全部帖子」「探索社區二手好物」「全部分類」或任何解釋性廢話。所有 UI 文案使用繁體中文；商品標題、描述、價格屬於帖子資料，可使用假資料。整體感覺要像精品電商與社區交易平台之間的高質感展示頁。

## 整體結構

1. 外層頁面
   - 頁面上下留白：桌面約 `32px`，手機約 `24px`。
   - 垂直區塊間距：`48px` 至 `56px`。
   - 每個主要內容區使用全站 `section shell` 置中，內容最大寬度接近 `1280px`。
   - 背景保持乾淨，不使用裝飾性卡片堆疊。

2. 首個視窗推薦好物區
   - 桌面版使用兩欄 grid：
     - 左側大型推薦卡，約佔 `1.55fr`。
     - 右側推薦欄，約佔 `0.8fr`，最小寬度 `22rem`。
   - gap 約 `20px`。
   - 桌面高度：`clamp(34rem, 100svh - header height - 4rem, 42rem)`。
   - 左側大型推薦卡最小高度 `32rem`。
   - 右側推薦欄包含 3 張小卡，桌面垂直堆疊且等高；平板可改為三欄橫排；手機堆疊。

## 推薦卡片樣式

1. 大型推薦卡
   - 整張卡片可點擊。
   - 圓角使用大圓角，例如 `rounded-feature` 或 24px 左右。
   - 圖片鋪滿，`object-cover`。
   - hover 時圖片 scale 約 `1.03`。
   - 使用由下至上的黑色漸層遮罩：
     - bottom 黑色 72% 透明度。
     - middle 黑色 18% 透明度。
     - top 透明。
   - 文案固定在左下角：
     - kicker：「推薦好物」，小型 uppercase 風格，白色 72%。
     - 標題：display font，桌面可到 56px 或 60px，最多約 3 行。
     - 描述：白色 82%，最多 2 行。
     - 價格：display font，約 36px 至 40px。
   - 內距：手機 24px，桌面 40px。

2. 右側三張推薦卡
   - 每張都是可點擊圖片卡。
   - 最小高度 `14rem`。
   - 圓角與大型卡一致。
   - 圖片鋪滿，hover scale 約 `1.04`。
   - 使用底部黑色漸層遮罩。
   - 文案在左下角：
     - 標題 18px，兩行截斷。
     - 描述 14px，兩行截斷。
     - 價格 24px display font。

## 分類展示區

推薦區下方是多個分類 row，每個主類一行。分類不要用篩選面板形式呈現，而是像商品陳列區。

1. 分類 row 外觀
   - 每行頂部有分隔線，顏色使用全站 border 的 64% 透明度。
   - row 頂部 padding `32px`。
   - row 之間垂直間距 `32px`。

2. 分類 row 標題列
   - 左側：
     - 主分類名稱，例如「家具家居」「家電影音」「兒童用品」「運動戶外」。
     - 標題使用 display font，桌面 36px 至 40px。
     - 下方顯示「N 件好物」，14px muted。
   - 右側：
     - pill 按鈕「更多」+ arrow-right icon。
     - 邊框為主色 22% 透明度。
     - 背景為主色 8% 透明度。
     - 文字使用主色。
     - 點擊後可跳到 Filter page 並帶入對應分類。

3. 分類內容區
   - 桌面版使用 grid：
     - 左側分類輪播圖寬 `21rem`，大桌面 `24rem`。
     - 右側為橫向可滾動商品 lane。
   - gap 約 `20px`。
   - 手機版上下堆疊。

## 左側分類輪播卡

- 高度至少 `23rem`。
- 圖片鋪滿，`object-cover`。
- 使用底部黑色漸層遮罩。
- 文案在左下角：
  - 標題 24px，最多 2 行。
  - 描述 14px，最多 2 行。
  - 價格 30px 左右。
- 右上角有兩個圓形 icon button：
  - arrow-left。
  - arrow-right。
- 圓形按鈕尺寸約 `2.35rem`。
- 按鈕背景白色 18% 透明度，邊框白色 42% 透明度，使用 backdrop blur。

## 右側橫向商品 Lane

- 使用水平滾動，不換行。
- 每張卡片尺寸：
  - 寬 `15.5rem`。
  - 高 `20rem`。
  - 不縮放，`shrink: 0`。
- 卡片是圖片背景，使用 bottom overlay。
- hover 時上移 `3px` 並加深陰影。
- 文字全部固定在左下角：
  - 商品標題 18px，最多 2 行。
  - 商品描述 14px，最多 2 行。
  - 價格 24px display font。
- 水平 scrollbar 可以保留，但要細且低調。

## 視覺規則

- 這是一個展示頁，不是搜尋頁。
- 不要放左側篩選、不放 tabs、不放多餘介紹。
- 使用大量真實商品圖片或高質量生活方式圖片。
- 卡片文字必須在圖片左下角，避免跑到圖片外。
- 所有圖片卡都需要黑色漸層遮罩以保證文字可讀。
- 圓角、陰影和邊框要保持一致。
- 不使用表情符號。
- 品牌感要正式、乾淨、成熟。

## 響應式要求

- 小於 `1024px`：
  - 推薦區高度改為 auto。
  - 右側推薦卡可改成三欄或自然堆疊。
  - 分類內容區改為上下排列。
- 小於 `640px`：
  - 標題字級縮小。
  - 推薦大卡保持至少 `28rem` 高。
  - 商品 lane 可水平滑動，卡片寬度保持接近 `15rem`。
