# Marketplace Filter Page UI Prompt

## 可直接使用的 Prompt

請建立一個「香港高端社區二手交易平台」的二手商品篩選頁。整體風格要正式、乾淨、克制，像精品電商的商品篩選頁，不要做成社群 feed，也不要出現行銷說明文字。頁面文案使用繁體中文，商品帖子本身可以使用假資料，商品標題、描述、價格、地點、時間屬於資料內容，不要當作固定 UI 文案。

頁面需要在頂部導覽列下方呈現，主內容高度為 `100vh - header height`，桌面版固定為左右兩欄：左側是篩選欄，右側是商品結果。整個內容容器最大寬度約 `1280px`，水平置中，內距桌面為 `64px 32px`，左右欄距 `48px`。桌面版不讓整個頁面滾動，而是左側篩選欄和右側結果區各自垂直滾動；手機版改為上下堆疊並回到正常頁面滾動。

## 版面結構

1. 外層主容器
   - 使用 flex row。
   - `max-width: 1280px`，`margin: 0 auto`。
   - 高度為扣除頂部導覽列後的視窗高度。
   - 背景使用接近白色的暖灰底，例如 `#F9F9F7` 或 app surface。
   - 主要文字色為 `#1A1C1B`。

2. 左側篩選欄
   - 固定寬度 `16rem`。
   - 高度填滿主容器。
   - 右側留 `0.5rem` 內距，隱藏可見 scrollbar。
   - 欄內元素垂直排列，區塊間距 `32px`。
   - 頂部為標題列：
     - 左側標題：「篩選」，字體 24px，display font，medium。
     - 右側文字按鈕：「全部清除」，14px，深墨綠。
     - 下方有 `#E2E3E1` 分隔線。

3. 篩選區塊
   - 每個區塊標題使用小型 uppercase 標籤風格：
     - 12px，font-weight 600，letter-spacing 0.1em。
     - 顏色 `#717878`。
   - 區塊之間使用頂部分隔線 `#E2E3E1`，內距 `24px`。

4. 分類區
   - 標題：「分類」。
   - 多列 checkbox，每列左右分佈：
     - 左側 checkbox + 分類名稱。
     - 右側灰色數量。
   - checkbox 尺寸 `16px`，圓角 `4px`，選中顏色 `#002727`。
   - 分類文字 16px，行高 1.6。

5. 價格範圍
   - 標題：「價格範圍」。
   - 兩個輸入框，中間用短橫線分隔。
   - 每個輸入框左側有 `$` prefix。
   - 輸入框高度 `40px`，背景 `#F4F4F2`，圓角 `4px`，無邊框。
   - placeholder 為「最低」與「最高」。

6. 成色
   - 標題：「成色」。
   - 使用 pill chip button：
     - 「全新」「近乎全新」「良好」「可用」。
   - 選中狀態：邊框 `#002727`，背景 `rgba(0,39,39,0.05)`，文字 `#002727`。
   - 未選狀態：邊框 `#C1C8C7`，文字 `#414848`。

7. 地區
   - 標題：「地區」。
   - 一個 select 欄位，左側有 location icon，右側有 chevron-down icon。
   - 選項包含「全部地區」「半山」「山頂」「淺水灣」「跑馬地」。
   - select 高度 `40px`，背景 `#F4F4F2`，無原生箭頭。

8. 只顯示圖片
   - 一列 toggle switch。
   - 左側文字：「只顯示有圖片的帖子」。
   - 右側 switch 寬 `40px` 高 `24px`。
   - 未選背景 `#E2E3E1`，選中背景 `#002727`，白色圓點滑動。

## 右側結果區

1. 結果頂部列
   - 左側顯示「N 個結果」，18px，顏色 `#414848`。
   - 右側是排序控制。
   - 排序文字：「排序」，16px，顏色 `#717878`。
   - select 寬約 `9.75rem`，文字 14px medium，右側 chevron-down 靠近文字，不要拉太遠。
   - select 不要與 label 重疊；在窄寬度時允許換行。

2. 商品結果 grid
   - 桌面：三欄，gap `32px`。
   - 平板：兩欄。
   - 手機：一欄。
   - 每張卡片：
     - `min-height: 25rem`。
     - 背景 `#F9F9F7`。
     - 邊框 `#E2E3E1`。
     - 圓角 `12px`。
     - 陰影非常輕，hover 時加深。
   - 圖片區：
     - 高度 `12rem`。
     - 圖片 `object-cover`，hover 輕微 scale。
     - 無圖片時用淺灰背景和 picture icon。
     - 右上角可有小 badge：「全新」，白色半透明背景。
   - 內容區：
     - padding `24px`。
     - 第一列：左側商品標題，右側價格。
     - 標題 24px display font，單行截斷。
     - 價格 20px display font，深墨綠 `#002727`。
     - 描述 16px，行高 1.6，最多兩行。
     - 底部 meta 有頂部分隔線：
       - 左側 location icon + 地區文字。
       - 右側時間文字。

3. 分頁
   - 在結果底部置中，距離 grid 約 `64px`。
   - 圓形按鈕 `40px`。
   - 目前頁為深墨綠背景 `#002727`，白字。
   - 其他頁為白底或透明底，邊框 `#E2E3E1`。
   - 包含上一頁、1、2、3、省略號、12、下一頁。

## 視覺規則

- 主色：深墨綠 `#002727`。
- 文字深色：`#1A1C1B`。
- 次文字：`#414848`。
- 輔助文字：`#717878`。
- 邊框：`#E2E3E1`。
- 淺背景：`#F4F4F2`、`#F9F9F7`。
- 不使用表情符號。
- 不使用大段說明文，不要放「如何使用」之類的提示。
- 介面要像可正式上線的篩選頁，而不是概念稿。

## 響應式要求

- `max-width < 768px` 時：
  - 主容器改為 column。
  - 高度改為 auto，`min-height` 保留扣除 header 的視窗高度。
  - padding 改為 `40px 20px`。
  - 左側篩選欄寬度 100%，不再獨立滾動。
  - 右側結果區不再獨立滾動。
  - 商品 grid 單欄。
