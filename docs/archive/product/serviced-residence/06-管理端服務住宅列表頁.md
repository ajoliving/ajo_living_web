# 管理端服務住宅列表頁

## 頁面目標

讓管理員檢索、審核與維護平台內所有服務住宅。頁面需要以效率與風險控制為主，展示足夠的資料讓管理員快速判斷是否需要處理。

## 頁面結構

1. 頁面標題
   - 服務住宅管理。

2. 搜尋與篩選
   - 關鍵字：住宅名稱、地址、發布者、電話。
   - 狀態：全部、草稿、待審、上架中、已下架、已過期。
   - 地區。
   - 廣告等級。
   - 發布者類型：業主、代理。
   - 建立時間區間。

3. 表格欄位
   - 封面。
   - 住宅名稱。
   - 發布者。
   - 地區。
   - 最低價格。
   - 房型數量。
   - 圖片數量。
   - 廣告等級。
   - 狀態。
   - 更新時間。
   - 操作。

4. 操作
   - 查看公開頁。
   - 編輯。
   - 上架 / 下架。
   - 標記過期。
   - 查看聯絡資料。

## 管理需求

- 管理員編輯後需要完整保留全部服務住宅欄位。
- 管理端與會員中心編輯頁應保持字段一致。
- 操作需要有確認彈窗，避免誤下架。

## 視覺需求

- 使用管理後台風格。
- 表格密度較高，但文字不能擠壓重疊。
- 狀態與風險提示需要清楚。

## Stitch 生成重點

請生成一個 B2B 管理後台服務住宅列表頁。重點是表格效率、篩選能力和操作清晰，不要使用行銷式視覺。
